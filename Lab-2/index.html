Мова розмітки HTML

HTML (HyperText Markup Language) — це стандартна мова розмітки для створення веб-сторінок. Вона описує структуру документа за допомогою елементів, які браузер перетворює на видимий вміст.

Основні елементи

Найчастіше під час розмітки тексту використовують такі елементи:

  • заголовки (h1–h6);
  • параграфи;
  • списки;
  • зображення та посилання.

Етапи створення сторінки

  1. Створити файл із розширенням .html.
  2. Додати базову структуру документа.
  3. Наповнити сторінку вмістом.
  4. Відкрити файл у браузері та перевірити результат.
